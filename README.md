# Vivaah AI

Premium, privacy-first matrimonial platform. Product requirements and architecture are in `docs/`. The current web and Expo mobile clients are UI prototypes with illustrative data only; backend, real identity, matching, payment and social-provider integrations remain planned work.

## Local development

Web: `npm install && npm run dev`

Mobile: `cd apps/mobile && npm install && npm start`

## Product principles

- Five independent matching dimensions: Preference, Horoscope, Social Connect, AI Compatibility and self-declared Ideology & Values.
- Social Connect uses only mutually consented, officially accessible data or manually curated interests. No scraping or hidden sensitive inference.
- No production readiness claim until security, privacy, tests and operational gates pass.
